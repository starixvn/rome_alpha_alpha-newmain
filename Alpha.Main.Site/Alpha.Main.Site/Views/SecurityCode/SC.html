Security code rules

Security Code (SC) must be a 6-digits string, contains at least 2 different digits and must not be forward run and backward run number.

  • A "Forward run" is a consecutive, ascending order series of digits.
  • A "Backward Run" is a consecutive, descending order series of digits.
  • For example: 123456, 456789, 765432, ect. are not allowed
